
# Bacterial Alginolytic Screening

Collection of R scripts used for exploratory bioinformatics analyses of bacterial populations with potential alginate-degrading activity.

## Project overview

This repository contains scripts developed during the analysis of environmental sequence datasets. The code was used to process, filter and characterize biological sequences and perform statistical comparisons between samples.

## Included analyses

- Filtering sequences from FASTA files
- Selecting sequences by sample, region and enzyme family
- Grouping sequences by length
- Statistical comparisons between sample groups
- Exporting processed datasets for downstream analysis
